# Oracle_Agentic_AI_Labs
Hands-on labs, practical implementations, and projects completed while pursuing the Oracle Agentic AI Certification, covering AI agents, LLMs, tool calling, workflows, and agentic AI concepts.

I completed the Oracle Agentic AI Foundations learning path, exploring Generative AI, Large Language Models (LLMs), prompt engineering, AI agents, workflows, and agent architectures. I learned about LangChain, tool calling, the ReAct pattern, the OpenAI Agents SDK, OpenAI APIs, and multi-agent orchestration. I also studied Retrieval-Augmented Generation (RAG), embeddings, vector databases, semantic search, function calling, and guardrails to understand how AI agents retrieve information, use external tools, and generate reliable responses.

I also explored Oracle Cloud Infrastructure (OCI) and its AI capabilities, including OCI Enterprise AI Agents, Agent Factory, managed model inference, hosted agent deployment, containerization, security, and governance. As a hands-on implementation, I built a Python-based MCP math server using FastMCP and connected it to a LangChain agent with a locally running Qwen 2.5 model through Ollama. This project helped me understand MCP client-server communication, tool discovery, and execution. Overall, the course strengthened my understanding of building, integrating, securing, and deploying agentic AI applications using modern AI frameworks and cloud technologies.
